스킬이 뭔가요? 스킬은 Claude에게 주는 "이런 상황엔 이렇게 행동해"라는 전문 설명서입니다. 대부분 여러분이 자연스럽게 말하면 Claude가 알아서 해당 스킬을 꺼내 씁니다. 예를 들어 "이거 기억해둬"라고 하면 remember 스킬이, 버그를 만나면 systematic-debugging 스킬이 자동으로 작동해요. 각 카드의 "이렇게 말하세요"가 그 발동 문구 예시입니다.
⚠️ 백엔드 필요 스킬 3종. watch, understand-*, agentmemory의 실사용 스킬은 아래 도구/서버를 한 번 설치해야 완전히 동작합니다. 안 깔아도 스킬 자체는 보이지만 실제 기능은 멈춰요.
🎬 watch — 영상 보기 백엔드 설치 방법

영상 다운로드(yt-dlp)와 프레임 추출(ffmpeg)이 필요합니다.

# macOS
brew install yt-dlp ffmpeg

# Ubuntu/Debian
sudo apt install -y ffmpeg && pipx install yt-dlp

자막 없는 영상은 음성 인식(Whisper)도 쓰며, 이 경우 OpenAI API 키가 필요할 수 있습니다.

🗺️ understand-* — 코드 이해 백엔드(npm CLI) 설치 방법

업스트림 플러그인을 빌드해 understand CLI를 만들어야 합니다.

# 원본 저장소를 받아 빌드 (Node.js + pnpm 필요)
git clone https://github.com/Lum1104/Understand-Anything
cd Understand-Anything && pnpm install && pnpm build

자세한 설치는 원본 저장소 README를 따르세요. (이 컨테이너 대신 로컬 설치 권장)

🧠 agentmemory — 장기 기억 백엔드(MCP 서버) 설치 방법

메모리 도구를 설치하고 MCP 서버를 실행한 뒤 Claude에 연결해야 합니다.

# 원본 저장소 안내를 따라 설치 + 서버 실행 후
# Claude Code에 MCP 서버로 등록 (connect 명령 사용)

설치/연결 절차는 agentmemory-agents, agentmemory-config 스킬과 원본 저장소에 정리돼 있습니다.
